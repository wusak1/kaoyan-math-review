# 考研数学批改与复盘执行规范

版本：2.7｜更新：2026-10-30｜默认科目：数学二

本版替代技能内 v2.6 的默认规则，在偶数页起题、原答图内文字订正及整卷复盘基础上，补充概念附录与多思路详解要求。题库定位、选题和版式细则分别见 [材料定位](local-materials.md)、[选题](exercise-selection.md)、[写作与版式](writing-and-layout.md)。不依赖旧对话；用户当次要求优先。示例题号、分数、日期均不得当作本次事实。

## 一、核对材料与原答

建立题号、小问、满分、题面页、作答页、答案页的内部台账。手写公式必须看图核验；OCR 只辅助检索。原卷、参考答案与题库均须独立判断，不以已有勾叉替代核验。

默认黑／深灰是原卷作答，蓝笔是闭卷独立订正，红色及其他彩笔是既有批改或看答案后的订正。当次笔迹说明优先。涂改处按可见最终原答处理，不因蓝笔正确改变原答分数。

确认空白记未作答；缺页记“缺作答页”；字迹不清在具体位置标“此处字迹待核”。后两者不直接计零，不按答案补写用户未写的步骤。先完成可判断部分，集中说明缺少什么。

## 二、数学核验与评分

- 先独立求解或核对，认可数学成立的等价表达和替代解法；题目限定方法时检查是否满足要求。
- 分值取题面，有正式评分细则则依细则；无细则按合理步骤估分。评分口径在概览中简述一次。缺少分值时说明所用假设，不伪造精确总分。
- 选择、填空按最终原答计分。有过程则核对；无过程但结果正确可写“答案正确”，不据此推断稳定掌握。
- 解答题同一前错向后传播不重复扣分，仍判断后续方法是否成立、是否因前错降低难度。废弃草稿不作为最终解答扣分。
- 有逻辑缺口不能只凭结果正确给足过程分；纯记号瑕疵应与数学错误区分。估分有合理浮动时保留区间，若取暂定值须与逐题取值一致。
- 参考答案不是默认正确，更不自动等于官方细则。冲突时复核题目版本和推导；仍无法判断则具体标出争议步骤。

### 本地答案与网络解法

每次编写解答，都须核对可用的本地答案册，并主动检索网络中的相关解法。此要求覆盖正文错题、附录中实际展开的正确题及补充练习；不因本地答案完整或自己已经会解而省略检索。未展开解答的正确题不因此强制加入附录。网络解法检索是每次必做步骤，与“本地练习不匹配时再向外选题”的规则不同。

- 本地按年份、题号匹配版本，读取对应解答、全部续页和其他解法；记录题面与答案的 PDF 起止页，不把年份书签当作逐题核对完成。
- 网络先用年份、科目、题号和关键条件检索原题，再按关键式、定理或构造检索相关方法。可合并查询，但须逐题确认覆盖。优先阅读院校、出版社、教材作者或解法原作者的完整页面、讲义或视频；转载及搜索摘要只作定位线索。视频记录相关时间段，无法读取的讲解不算已核验。
- 对比本地与网络的条件、方法及关键步骤，独立验证数学正确性与科目适用性。不同且有价值的解法一并整理成完整推导；同一思路的不同排版或代数改写合并。没有找到可靠的不同方法时保留已验证方法，不编造第二种解法。
- 工作记录逐题保存查询词、直接来源链接、访问日期、采用或未采用的理由。本地页码及实际采用的网络来源在该题解答末尾简短注明；由本人补足的步骤据实说明，不把本次推导冒称为来源原文或官方解答。
- 网络不可用、页面无法读取或没有找到可靠相关解法时，继续完成能验证的数学内容，并在交付说明中一次性指出受影响题目及检索缺项。未完成的检索不能称为完成，不把未检索与检索后没有新方法混为一谈。

## 三、分析深度

内部可用概念、定理、计算、方法、论证、审题、记号等类别组织工作，正文默认不展示 M1–M7、A/B/C 编码。

局部计算或抄写错误：批注指出具体行，给修正式和必要检验。批注可以简短，参考答案仍须覆盖全部小问与关键推导，不能只引用原答结论。

概念、方法或证明问题：说明原解成立到哪一步、随后为何不成立，尽量沿原思路完整推导。证明应写出定理适用条件和关键衔接；原路无法完成时说明原因并另解。

空白或过程不足：需要互动时问一个能区分卡点的具体问题；制作离线讲义时可在解析区写“可先检查……”并给完整解答，不将这类提示放入独立练习题面。

正确但繁琐：只在确有收益时补“另一解法”或一条注，不把所有正确题展开成完整讲义。同类问题可合并说明，不重复粘贴相同提醒。

蓝笔有订正时，直接写“蓝笔已改正”或“蓝笔末行仍漏负号”，随后给必要修正。没有历史作答，不写“反复出错”“一贯薄弱”。

### 解法的深度与比较

用户需要可独立学习的解答。每条实际展开的方法说明从题目哪一条件或目标想到、为何选择该公式／换元／辅助函数、适用条件、关键中间式和如何达到全部小问的结论；不能以“利用某定理即得”、只给方法名、结果或一句替代思路代替推导。原答卡住或出错处尤其要展开，证明题解释构造从何而来，参数题解释分类与退化情形。

主动寻找并比较有价值的不同方法，优先修复用户原思路，再提供可靠的不同入口。存在合适的多种方法时逐一完整展开，并简述各自适合什么结构、计算量及条件差异；不固定每题必须几种，不为数量引入超纲工具，不将同一算法的代数改写、参数重命名或同一对称区间改写算作独立方法。若只是同一模型下的不同积分计算，明确其层次；仅一种可靠方法时写透该法。补充练习的答案也适用，不把第二种思路停在一个未求完的式子。

### 未完成的其他解法

逐一辨认原卷中实际出现的不同尝试，包括旁支换元、倒数关系、辅助函数和未完成或划去的草稿。评分只依据最终原答；复盘仍分析具有学习价值的其他尝试，不因未成功而忽略，也不能把用户的换元替换成标准换元后声称已分析原思路。

每条不同思路说明：起始想法是否可行、成立条件、最早出错或停住的具体式子、错误原因及最小修正。可继续的沿该思路完成关键推导并与最终答案核对；不能继续的给出数学原因。特别核对变量依赖、求导自变量、倒数求导的非零条件、换元定义域和初值是否落在换元奇点。若前面已有错误方程，分别分析沿该方程是否又有独立错误，以及改正原方程后此方法是否仍可用。手写含糊时引用可确认的式子，不擅自替换变量或补造步骤。

这部分放在对应题的错因分析与参考答案中，以“原解中的另一种尝试”“沿原换元继续”等自然标题组织。只有等价的重复计算可合并；不能用网络另一解法或答案册解法代替用户未完成思路的分析。

### 错题知识点

按 [教材知识点分类](knowledge-classification.md) 只标注错题实际涉及的知识点。高数采用已核对的同济教材章、节名称，并注明版本；线代错题单独分类。每道错题末尾将“补充练习”合并为“知识点与补充练习”，先列本题知识点及教材定位，再列相关练习及解答。原题后不重复标注，不生成全卷知识点索引，不要求正确题或补充练习另列知识点。知识点用于回顾原题，练习题面不夹带具体做法或答案。

## 四、文档组织

整卷依次安排“批改概况—错题批改表—整卷复盘总结—各题订正—附录”。每道错题的原题、原答、分析、解答和补充练习连续编排，不再另设“原题重做”或全卷集中练习模块。单题任务按实际需要缩减。

### 首页与错题批改表

首页不设“使用顺序”或同义的阅读流程模块。原答估分用一行写清总分／满分；确有浮动时附区间，评分依据至多补一句。不要重复列示同一分数或展开评分流程。若存在缺页、分值未知等影响总分的问题，须简短说明，不为精简而隐去。

批改表只列错题，包括答错、过程有实质错误、未完成和确认未作答的题。采用“题号、原答得分／满分、简短批注、正文页码或链接”四列。正确题不列入表格；只有更简洁解法或记号建议的正确题放入附录。无法判断的题另作简短待核说明，不直接归为错题。

全卷仍须逐题核验和建立内部计分台账。总分由全部题目相加，不能拿只含错题的表格小计充当总分；已完成计分时可用满分减去各错题扣分复核。蓝笔订正不加回原答得分。

### 整卷复盘总结

每次整卷批改都须依据全卷计分台账与实际作答，给出整卷总结，不以逐题批注或分数表替代。说明各部分表现、已完成的有效方法、主要失分来源，以及下一轮复习与训练的先后顺序；无需展开所有正确题或生成全卷知识点索引。

将错误区分为“疑似粗心或局部执行失误”“概念、条件或方法需要加强”“多种错误混合”“未完成或证据不足”等自然类别，类别按本卷实际情况取舍。每类列具体题号、可见证据、相应改法及必要训练；给出失分小计时与总分核对，混合题不可重复统计。

不能仅凭漏号、计算错或答案正确就确认粗心或已掌握。原卷已有完整正确方法而只发生局部抄写、系数或代值失误时，可列为粗心型候选，并说明用不看答案独立复做来核实。过程不足或留空不猜测能力、作答时间与心理原因。训练建议应落实到可检验的数学步骤，不写空泛口号，也不自动安排提醒。

### 每道错题的编排

以下顺序固定，内容长短按错误性质调整，不为齐全标题堆砌空话：

1. **原题**：完整呈现题干、条件、小问，以及作答所需的选项、图形与符号。可依原卷准确重排，也可使用清晰题面裁图；不能仅给题号、出处链接或手写作答代替题目。重做就在此题进行，不另复制一遍到独立章节；用户需要书写空间时在题面后适量留白。
2. **原答与批注**：紧接原题放真实手写过程，包含判断所需的上下文和续页。优先在原答图的副本上标注最早出错的等式、推理或遗漏位置；在原答副本的对应步骤旁直接写明“错因＋更正方案（必要时给修正式）”，用编号或引线指向实际错步；细框仅辅助定位，不能只画框、把说明全部留给正文。优先使用原图空白，空间不足则扩展白边或增加局部放大图；避免覆盖笔迹。保留未标注原图，注明“本次批注”，不要与原卷已有红笔或蓝笔订正混淆。可辨别的后续独立错误另标，同一前错的传播不逐行重复标错。若问题是缺少步骤，在相邻位置注明“此处缺少……”；空白、缺页或字迹不清时如实说明，不虚构错误行。确实无法在图上清楚标注时，图下引用对应原式并写明行或位置。蓝笔与原答分别说明。
3. **错因分析**：先说明原解成立到哪一步，再说明从何处开始、因何不成立。区分计算错误、条件遗漏与推理缺口；评分依据在必要处简述。结论要有可见作答支持，不猜测学习习惯。
4. **解答思路**：解释由哪些条件或目标想到方法、为何适用、怎样连接主要步骤。多种方法先分别说明入口；不是只列定义或定理名称。与后面的完整演算分工，不重复整篇答案。
5. **参考答案**：给出完整、可核对的推导，按“解法的深度与比较”展开，优先修正用户原思路。存在不同且有价值的解法时一并写出，以“解法一”“解法二”等区分，各自说明条件并完成关键步骤；不只报方法名，也不将等价的代数改写凑成多种解法。局部笔误仍保留上述顺序，分析和思路可以各用简短一句；参考答案仍完整覆盖全部小问和关键推导，不以修正式或“原结论正确”代替。
6. **知识点与补充练习**：直接接在该错题的参考答案后，先简列本题知识点与教材章、节定位，再提供针对前述错误的练习；没有合适练习不强行填充。题面不夹带提示或答案。随后安排本组练习解答：PDF/打印 HTML 从新页开始，Markdown 默认折叠。该组练习及解答结束后再进入下一道错题。多道错题有相同问题时，练习放在关联最直接的一题之后，其余处交叉引用，不重复印题。

### 附录

附录包括本卷有证据需要补学的概念与方法，以及确有收益的正确题解答补充。概念题答错、定义混淆、定理条件遗漏、未想到但解题所需的知识或构造，应在附录安排专题补讲；正文保留具体错因与修正，并在题末链接对应专题。未作答而原因未知时，表述为补充可用知识／方法，不断言用户完全不会。

每个专题注明关联原题，按需要写清概念或定理的准确表述、适用条件、易混概念的区别、为何原答用法不成立；用一个能区分误解的反例或简短例子，并说明怎样用回本题。多题共用内容合并，避免逐题复制；正文的简短知识点定位仍放在各题末尾，不能用附录代替原题完整解答，也不把附录扩成无关的全卷知识索引。

正确题中确有必要保留的解答补充、较简洁解法或数学说明，置于附录的独立部分，按原题号编排，必要时附题面。没有相关补充则省略相应部分，不为覆盖全卷而逐题补写。打印版概念附录整体及附录原题尽量从偶数页开始，专题之间依内容连续或另页，长专题允许续页；不为每个非习题专题机械插入空白对页。

不要出现“考场三件套”“验收打卡”“破题信号”“易错雷区”“秒杀路线”等口号或其换名后的固定模块。方法选择、错误提醒和检验若有数学价值，应写进推导或一条“注”中。

## 五、练习与订正记录

执行 [选题与复习检验](exercise-selection.md)。以具体错误机制为依据，本地合适则用本地；没有合适候选就检索网络或其他可访问来源。缺一种题库不阻断整项批改，也不以凑数为由使用不匹配的题。

给出练习不等于完成练习，原题订正正确也不等于变式已会。只记录已看到的作答；没有新作答时写“未作答”即可，不在正文反复论述掌握度边界。用户提供日期才记录实际完成日期。后续重做时间可建议，不虚构已完成记录或自动创建提醒。

默认不生成“验收表”、打卡清单或反复的任务框。需要保存复习记录时，在文末简短列题号、作答日期、结果；用户要求可勾选待办时再使用原生 Markdown 任务列表。

## 六、两种媒介

PDF/HTML 采用教材式单栏 A4 版面，按 [版式规范](writing-and-layout.md) 的组件要求排版：深蓝主标题、黑色正文与小标题、三线式错题表、原答图内文字批注与非遮挡引线。正文各原题及独立补充练习尽量从偶数页（左页）开始，便于对开阅读；需要时插入有记录的对页留白。以最终PDF第一页为第1页核查真实页码，不以HTML屏幕位置代替。短题优先在一个对开内完整呈现；长题允许自然续页，不压缩字号或删减推导来强塞两页。预览工具栏不进入打印版。公式用 KaTeX/MathJax 等可靠方式渲染，不用 Unicode 拼凑复杂公式；长推导按等号或逻辑步骤断行。真实手写裁图保留上下文与笔迹颜色，不切断公式。

Markdown 使用 YAML 元数据（paper、date、score、status、tags），未知分数用 null，区间另记 score_range。日期为本次实际日期。图片相对引用，公式使用原生数学定界符。答案可用默认折叠的 Callout，题面不折叠；不将正文每段都放入彩色框。不得包含打印留白、PAGE 注释、物理分页符。

两端的分数、推导和订正记录应一致；不要直接以同一个带打印标签的 Markdown 兼任两种成品。

## 七、交付前检查

以下是内部检查，不作为成品章节：

- 逐题检查实际提供的解答是否完成本地答案及续页核对、网络相关解法检索和独立验证；检查全部小问、关键推导、方法入口与比较、适用条件及来源是否完整；可用的不同方法是否实际完成，概念附录是否与原答问题对应，未完成项如实注明。

- 用全卷内部台账核对总分和区间；表格只列错题，原答与蓝笔分离。检查重要公式、定理条件、参数分类和推导衔接。
- 检查首页无“使用顺序”、估分简短；每道错题具备完整原题与真实原答，标注与实际错误位置一致，依次为错因分析、解答思路、参考答案、相关练习；正确题补充只在附录；检查概念错误或必要遗漏是否有对应附录专题及正文链接。
- 核对选题针对性、科目范围、是否重复、原页与答案版本、适用勘误、简短出处能否定位。
- 检查题面页、目录及页眉是否泄露方法或答案；原题讲解可以在前，独立练习页本身须干净。
- 通读语言：删除过程播报、空泛评价和固定口号；必要的不确定性直接说清对象，不以追求流畅掩盖缺页或争议。
- 检查整卷复盘的分类依据、题号、失分小计、训练优先级；检查原答图上是否同时有具体错因与更正方案。
- 实际渲染并逐页检查公式、图片、分页、表格、孤立标题、截断和空白页；核对每题起始页是否为偶数，区分为对开安排的必要留白与意外空页；不是仅看生成成功日志。检查黑白打印辨识度。
- 核对 Markdown 的元数据、相对图片路径、数学定界符、折叠解答与链接。失败或缺材料时具体说明，不能称作完整交付。
