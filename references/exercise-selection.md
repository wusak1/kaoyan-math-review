# 选题与复习检验

选题先看需要补足的数学步骤，再看书名。本地资料便于读取可先查，但不拥有排他优先级。

## 从错解确定检验内容

将需要检验的步骤写成内部简句，例如“对含 x 外因子的复合函数再次求导时，是否同时对外因子求导”。不要只写“多元微分”“计算能力”。同时明确允许的方法、科目范围、所需前置知识和预期难度。

选择时依次比较：错误机制是否相同、关键推理是否必须出现、难度是否合适、是否能独立作答和核对。只有章节相同、公式外观相似，但不要求完成出错步骤的题，应放弃。只改数字的题可检验运算，不能单独检验方法迁移。

补充练习可以按匹配程度选择来源，但每道实际提供解答的练习仍须检索网络相关解法，具体执行当前批改规范的“本地答案与网络解法”。本地选题不免除这一步。

## 来源选择

1. 从 [本地导航](local-materials.md) 选择最可能命中的目录、书签或索引，不需要逐本遍历整库。
2. 候选不能检验具体错误、明显过难／过易、超范围、与原题重复，或找不到完整题面时，转向其他可访问资料或网络。不要等所有本地文件搜索完才允许转向外部。
3. 网络选题优先能核查原题的院校试题、出版社／作者材料、公开教材或可靠题库。用“具体结构＋关键条件＋题型”检索，不仅搜章节名。搜索摘要和答案聚合片段只能作为线索，需打开完整页面。数学推导自行复核，不照抄来源结论。
4. 外部来源记直接 URL、题目位置及访问日期；下载或引用遵守访问权限，不绕过付费限制。没有找到可靠题时，简要说明仍缺哪类练习，不编造出处。用户允许自编／改编时须明确标注，重新求解，不能冒充原书题。

## 题面、答案和勘误

- 本地题看原页图像及续页；外部题看完整原始页面或 PDF。核对条件、选项、图形、符号、年份／套次及版本。答案存在时读全并独立复核；答案缺失可独立求解，但须标“解答为本次整理”，不声称配套答案已核验。
- 有勘误的系列，选用前查适用条目；勘误与题面冲突时核对版本。未解决的关键歧义题不收入独立练习。
- 不把其他数学科目的标签直接当作超纲依据；按实际考查内容筛选。数二练习排除依赖数二范围之外知识的题。
- 跨题库去重：真题册、一本通、大观可能收录同一道题。按题面结构和条件辨别同题，不按书名或题号去重。错题正文中的原题可供重做，但不能计作新的变式练习，也不另设集中重做章节。
- 题面裁图不能带入相邻解析、手写提示、方法目录或勘误说明；必要时按已核对的正确题面重排，解答区说明采用的更正。

## 练习的位置

每道错题的参考答案后设置“知识点与补充练习”：先列该错题涉及的知识点及教材定位，再接相关练习，不集中放到全卷末尾。这里允许回顾原题知识点，但练习题面仍不夹带具体解题提示。每组先列完整、无提示的题面，再给本组解答：PDF/打印 HTML 按空间采用共用右页题面／答案普通翻页，或独立左页题面／右页答案；Markdown 解答强制用默认折叠的 `[!check]- 补充练习解答`。分页选择器及相邻结构见 [写作与版式](writing-and-layout.md)。之后再进入下一道错题。出处及选题联系随练习解答给出，不提前泄露方法。

多个错题考查同一缺口时，练习放在关联最直接的一题后，其余题只交叉引用；不重复印题。没有可靠、合适的题时说明所缺内容，不用不匹配的题填满模块。

## 数量与结论

整卷通常选 4–8 道，按实际缺口减少或适当调整，不视为硬指标。不要求每个错误机械配两题：小笔误用一小题；概念／方法问题可选一题巩固，再选一题改变条件或表达形式。多题针对相同薄弱步骤时合并。

解析区用一句自然说明交代练习联系，例如“此题仍需对外因子求导，但内层函数换成了隐函数。”练习题面处不写这句话。完成标准应是能独立写出关键步骤并得到正确结论；若涉及证明，应补全适用条件。

后续用户提交练习作答时，按原缺口检查是否再次出错，并区分新出现的错误。只根据实际作答说“本题已改正”“这一变式能独立完成”，不从一次正确推断整章已经掌握。无作答时留“未作答”，不写自动通过，也不使用打卡或验收口号。
