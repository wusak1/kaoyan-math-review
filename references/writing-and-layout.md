# 教材式表达与版式

版本：2.8｜更新：2026-10-30｜与批改规范 v2.8 配套。

## 语言

参照中文数学教材和习题解答：先给数学事实，再解释依据，随后推进计算或证明。使用“由……得……”“由于……，故……”“这里需注意……”等自然衔接；不把所有段落硬套同一句式。

批注要具体到式子或步骤，语气平实。不要写宣传式评价、夸张比喻、对话式打气，也不要把内部诊断术语换成另一套口号。错题以“第 16 题”等题号为标题，依次使用“原题”“原答与批注”“错因分析”“解答思路”“参考答案”“知识点与补充练习”。各段详略随题目调整；解答内部按需使用“解”“证明”“注”“解法一”“解法二”，不添加空泛栏目。

避免“精准定位、靶向赋能、闭环、抓手、秒杀、破题信号、易错雷区、考场三件套、验收打卡”等语言。默认无 emoji、M 类编码、反复的方括号状态串。并非简单替换词语，而是删除没有数学内容的句子。

| 不采用的表达 | 教材式写法 |
|---|---|
| 已形成二阶求导闭环，但仍须强化负号风险意识 | 二阶导数的各项已补齐，末项代入时仍漏了负号。 |
| 不能笼统诊断为不会链式法则 | 一阶导数正确。再次求导时，外因子 x 也应求导。 |
| 破题信号：看到 ff''+(f')² 秒想到构造 | 由 (ff')'=(f')²+ff''，可将左端写为一个乘积的导数。 |
| 验收打卡：完成变式并达成迁移 | 练习 2 改变了内层函数，可用来检查二次求导时是否仍有漏项。 |
| 首个实质错误位于第二行，具体根因待确认 | 第二行把 ln(1+x) 写成了 ln x。若这是抄写错误，从此行改正后继续计算即可。 |

上表的行内公式仅为语言示意；正式输出应采用标准数学渲染。没有实际作答支持时，不能照搬示例诊断。

整卷批改须另有基于题号与原答证据的复盘总结，列出粗心型候选、需强化的方法、混合错误及未完成情况，并说明复做或训练重点；不以逐题解析代替整卷分析。

### 详略

- 单一笔误：批注一小段加修正式即可；参考答案仍完整覆盖全部小问与关键推导。
- 推导卡点：写足条件、关键等式与解释；不要为了“简洁”跳过恰好需要补学的步骤。
- 证明题：先交代构造目的和条件，再用定理，不只报出定理名。
- 同一提醒只在最相关的位置说一次。表格给结论，详析给依据，概况给重点，各处不复制整段。
- 内部规则通常不写进讲义；真实缺页、无法读清或答案争议应明确说明对象，不能只追求流畅而省略。

### 概念附录与多种思路

概念题答错、必要知识或构造未想到时，在附录安排关联原题的专题。写清定义、条件、区别与反例，再回到本题；正文题末可跳转。正文简短知识点定位仍保留，不将附录写成全卷索引。

方法段解释“如何从条件或目标想到”，推导段补足关键等式。证明题写出构造的来源；计算题说明换元为什么简化。不同入口有价值时分别展开至结论，并比较适用结构；同一方法的等价计算明确标注层次，不凑数量。

## 打印版

默认采用单栏教材版，正文黑色，标题可用一种深色。无渐变、大面积色块、卡片堆叠、装饰性图标和专门的巨幅封面。用字号、字重和留白形成层次，边线只服务于表格或注释。

起始参数见 [review.css](../assets/review.css)：A4；左右及顶部页边距 17.5 mm、底部 18 mm；正文 11 pt、行距约 1.65；一级标题 20 pt、二级 15 pt、三级 12 pt；注和出处 9 pt。中文正文优先宋体类，标题用黑体类；实际字体不可用时选择可嵌入、字符齐全的替代字体并检查渲染。不要压缩至过小字号以减少页数。

首页不放“使用顺序”；原答估分通常一行，必要说明至多一句。正文按错题连续编排，概念与方法专题、正确题的解答补充置于文末附录。

### 单题对开的空间分配

左页（偶数页）为诊断与重做区，依次放题号、原题、原答与批注、图下本次批注、错因分析（末尾一句重做核验指令），再放 `.workspace.redo` 原题订正留白框。核验指令说明从哪一步重算、检查什么条件或符号，不写最终答案。右页（奇数页）的 `.question-solution-pane` 放解答思路、参考答案、知识点与补充练习；完整推导不提前复制到左页。

A4在既定页边距下的正文高度约261.5 mm。左页先为订正留白预留空间，再安排题面、真实原答图与分析；`.workspace.redo` 默认至少45 mm，计算或证明步骤较长时按需要增加，不能只有装饰性窄条。扣除留白及其边距后才是诊断内容预算，不以固定高度撑满整页，不用溢出隐藏裁字。短题争取一个对开完整呈现；右页先完整放主解，再排次级拓展解法。

内容过长时先去掉无关图外空白、拆分长原答并保留上下文、精简重复叙述，不能缩小正文或原答到难读、覆盖笔迹或删关键步骤。超长题允许多个对开并标明续页，诊断与详解起点仍须满足左右页约束；不能对整题、整个诊断区或长解析使用 `break-inside: avoid`。只保护标题及后续首段、短公式组、单张图、单行表格；长推导按数学步骤自然分页。页末不得孤立标题或产生意外空白末页。

### 左右页分页与前导页

`@media print` 必须使用本文件后附的 `left`／`right` 规则：`.question`、`.exercise.standalone`、`.appendix` 从左页开始，`.question-solution-pane` 和独立练习的 `.exercise-solutions-page` 从右页开始。严禁对 `.question`、所有 `.exercise` 一刀切写 `break-before: page`；普通换页无法表达奇偶页要求。生成器后置的内嵌 `<style>` 也不得恢复旧规则，避免覆盖 `review.css`。

首页“批改概况—错题批改表—整卷复盘总结”自然连续排版，不加硬性换页。首题的 `break-before: left` 应由支持左右分页的打印引擎补齐对页；后续题也由相同规则衔接。文档按左到右、PDF第一页为第1页／右页计数，偶数页为左页。不能用屏幕滚动位置、CSS语法被接受或导出成功代替最终PDF页码核对。

### 补充练习的弹性分页

- **共用右页**：错题详解结束后，若右页下方足以放完整练习题面及相应书写空间，使用普通 `.exercise`，不设硬换页，紧接知识点。对应答案普通翻页 `break-before: page`，避免与题面同页；不要求这组答案一定在奇数页。
- **独立对开**：解析占满右页、练习自然滑到新页，或余量放不下题面和书写空间时，将该练习改为 `.exercise.standalone`，用 `break-before: left` 从下一左页开始，答案用 `break-before: right` 从右页开始。不能只因屏幕上看起来有空就选择共用。

练习题面与其解答为相邻兄弟块；共享分支用更具体的 `.exercise:not(.standalone) + .exercise-solutions-page` 覆盖全局答案右页规则。若生成器需要额外包装，必须提供同等明确的共享分支类和选择器，不能使例外失效。打印版短练习通常留35–55 mm，计算／证明可留70–110 mm或按需要增加；结合实际分页决定分支，不强塞在右页余量中。

批改表只列错题，不夹入正确题或正确题的解法说明。四列可按 9%／15%／60%／16% 分配，第三列只放短批注，长式移入正文。仅用必要横线和浅表头底色，续页重复表头。不得把整张长表锁在一页。

长公式优先 aligned 等环境分行，按等号或逻辑关系对齐；不要缩小整页、裁切或在打印中依赖横向滚动。正文左对齐，避免中文两端强制拉伸造成疏密不均。

每题先呈现完整题目，再放手写原答；图题和长条件不得漏掉。手写图只裁掉无关空白，保留错误行与判断所需上下文。最早出错的位置优先在副本上用细框、引线或边注标出，原答图副本的相应步骤旁必须写具体错因和更正方案，必要时附修正式；用编号或引线与错步对应，框线仅辅助定位。空间不足时扩展白边或作局部放大，不覆盖原字；不遮挡原式，不仅靠颜色辨认。保留原图，图注注明“本次批注”，与原卷已有笔迹区分。长图分段后仍须能辨别步骤先后。上下排优先；并排只有在两图文字仍清楚时使用。不设置过小 max-height 压缩长图，必要时拆图并标续。

原题订正使用一层克制的细边留白框，不印密集方格，不预填答案；独立练习留白同样不与其答案共页。页脚放简洁页码，出处随解析而非抢占页眉。

## Markdown：Obsidian／平板主动提取

与打印版保持相同的数学、得分和题目顺序，但不复制物理页码或留白。每道错题的“原题—原答批注图—本次批注—错因分析（含末尾重做核验点）”直接可见；核验指令不写最终答案，供用户先在纸上或平板笔记中闭卷重做。

**强制折叠解析区。** 将“解答思路”与“参考答案”整体放进默认折叠 Callout，标题必须为：

```markdown
> [!summary]- 解答思路与参考答案（完成上方重做核验后展开）
> ### 解答思路
> 说明从题目条件如何想到主方法。
>
> ### 参考答案
> **解法一：沿原答思路修正。**
> 主解的完整推导写在这里。
>
> > [!note]- 拓展解法与比较
> > **解法二。**
> > 保留完整推导、条件与方法比较。
```

`-` 表示默认收起，不能改成 `+` 或直接展开。拓展解法优先采用上述二级折叠；客户端不支持嵌套时，在外层默认折叠区内用分割线及清晰标题区分主解与拓展，不能把拓展解法移到外层泄露。所有属于解析区的空行、公式、列表和表格都须保留外层 `>` 前缀，二级折叠则保留 `> >`，避免正文意外逃出折叠块。公式用原生数学定界符，不在每行重复开关定界符。默认收起符号与嵌套写法参见 [Obsidian Callouts 官方说明](https://obsidian.md/help/callouts)。

**强制折叠练习解答。** 知识点与补充练习题面直接显示，练习答案统一用：

```markdown
### 知识点与补充练习

本题知识点及教材定位。随后是完整、无提示的练习题面。

> [!check]- 补充练习解答
> 本组练习的完整解答、方法比较与出处。
```

各组练习的答案紧随该组题面，不集中到全卷末尾。题面不夹带方法标签、具体提示或会泄露解法的选题说明。上述两个层次均为默认规则，不再以“需要隐藏答案时”决定是否折叠。

不要输出 `.workspace.redo` 等HTML打印留白、PAGE注释、分页符、固定宽度或手动空行填页。保持相对图片、可用跳转和原生公式。默认用普通订正记录；用户要求勾选时才用 `- [ ]`，实际完成才标 `[x]`。

## 版面检查

使用样式表只是起点，不能替代实际渲染。检查最长公式、最长批注、最大手写图、跨页表格和题答边界；再逐页看是否有孤立标题、截断、过度留白、溢出或空白末页。屏幕阅读版和打印版都需检查：初始折叠状态只露出诊断与题面，展开后核对所有主、次解法仍完整；打印版逐题记录左页诊断和右页解析的起始页、订正留白、练习分支与其答案页。数学内容正确后，再润色和调整版式，避免润色改变条件或结论。

## 版式组件与生成要求

参考用户指定的 [Gemini 排版方案](https://share.gemini.google/VrXQUzDQaNU0)，采用其教材式层次、三线表及非遮挡批注设计。示例题目、估分、手写示意和出处仅是演示数据，不得写入真实批改。

- 页首使用 `.doc-header`：标题、简洁估分 `.score-summary` 与细横线。正文为 #111111，题号及主标题为 #1A365D，辅助文字为 #475569；三级标题保持黑色，避免所有标题同样醒目。
- 错题表使用 `.summary-table`：上、下边线 1.2 pt，表头下线 0.75 pt，行间线 0.5 pt；无竖线，浅灰表头，四列起始比例 9/15/60/16。列宽依实际内容微调，不能挤坏题号或公式。
- 原答使用 `.handwriting-canvas`；`.annot-box` 为透明暗红虚线框，`.annot-callout` 为图外文字批注。坐标须按真实裁图核对，不能照搬示例百分比。批注使用编号、引线和“本次批注”文字，直接在原答图副本的留白内呈现错因与改法，不能只画虚线框。黑白打印仍须能辨认。长原答分段后逐图标注，不将整题锁在一页。Markdown 使用同样可见的批注副本，不能依赖 CSS 才能看见错误位置。
- “解”“证明”“解法一”“注”以 `.math-lead` 或 `.math-note` 加粗起首，不做彩色胶囊。长证明按推理段落自然分页，短公式组才禁止拆开；数学字体及资源随交付打包。
- HTML 可附 `.preview-toolbar`，提供 A4 宽度、连续阅读、黑白预览和打印按钮，打印时隐藏。A4 宽度预览不声称是真实分页；实际分页以打印预览或导出 PDF 为准。不得用固定 297 mm 容器截断内容。灰度预览仅作用于文档，不改变真实原图颜色。
- `.question-diagnosis-pane` 包含题号与左页诊断重做内容，`.question-solution-pane` 包含右页思路、主解、拓展解法及知识点；不要只给标题加分页而让后续内容跑回左页。
- `.workspace.redo` 是诊断末尾的订正留白框；`.alt-solution` 是完整拓展解法的次级容器，不得用省略推导或过小字号实现主次。
- 练习及答案使用下述两种配对结构；打印前如有HTML折叠内容须全部展开，导出后恢复屏幕状态，防止漏印。页码由实际导出生成，不写死，不与浏览器页眉重复。

生成器应加载当前 `assets/review.css` 并输出对应语义类。检查旧的内嵌样式是否覆盖新字号、表格比例、图片宽度和分页规则；仅替换 CSS 文件不等于已有成品已更新。交付前查看真实页面与打印输出，验证工具栏不入纸、长公式不溢出、图片清晰且批注位置准确。

错题末尾的“知识点与补充练习”先列本题知识点和教材定位，再列练习；使用普通文字，不另设知识点卡片，不在原题后重复标注，不生成全卷知识点索引。


### HTML结构与CSS实现（v2.8）

    <div class="alt-solution"><!-- 解法二等完整拓展推导与比较 --></div>
    <!-- 知识点与练习引介；不提前展示练习答案 -->
  </div>
</section>
<!-- 共用右页：这一对相邻块中的答案仅普通翻页 -->
<section class="exercise"><!-- 完整题面及书写空间 --></section>
<section class="exercise-solutions-page"><!-- 完整练习解答 --></section>
<!-- 独立对开：另一组练习从左页开始，答案从右页开始 -->

<section class="exercise-solutions-page"><!-- 完整练习解答 --></section>

不要保留 `.practice-start`、`.answers-start` 等旧类上的泛化换页作为新组件的隐含入口；制作时统一迁移组件，检查外层包装、内嵌样式、旧 `page-break-before` 别名及 `!important` 是否覆盖规则。附录整体只有一个 `.appendix` 包装，内部非习题专题不逐个套用它，以免每节都补空白对页。

### 打印引擎能力核验

`left`／`right` 的规范含义是按需要产生一或两次分页，使后续内容落在指定侧页；见 [W3C CSS Fragmentation §3.1](https://www.w3.org/TR/css-break-3/#break-between)。第一张PDF按右页编号；对开要求以导出的实际页序为准。首题规则应自动补齐的前导留白必须在最终PDF中确认，不能仅凭规则写进CSS就保证浏览器已经补齐。

实际使用的浏览器／导出器须用含前导页、短题、长解析、共享练习与独立练习的样例验证奇偶、自然分页和答案隔页。若其实现仅把 `left/right` 当成普通换页，保留规范CSS，改用经验证支持左右分页的引擎，或在兼容分页流程中同时约束诊断、解析和练习的全部左右锚点并重新核验全部页码与跳转；不能退回一刀切 `page`，也不能只补偶数题首页而漏掉右页解析与练习例外。未解决的页侧约束须如实说明，不声称对开已验证。


兼容分页的操作顺序：先用规范CSS导出，再记录每道 `.question`、每个 `.question-solution-pane`、`.exercise.standalone`、其答案及 `.appendix` 的实际起始页和目标侧；共享练习答案只要求与题面隔页，不附加奇偶限制。按实际页序逐个检查，侧页不符时在该锚点所在页前插入必要空页，后续页码随之重算；不能只处理题号锚点。插页须保留／更新内部跳转、目录及连续页码，并重新检查所有锚点。共享练习若已自然滑出预定右页或其书写空间不足，应先改成独立练习重新导出，不能用插页掩盖空间分配错误。

本机能力记录：2026-10-30 用 Chrome 154.0.8037.98 实测一页和两页前导的样例，计算样式正确，但没有按 `left/right` 自动补齐侧页；例如两页前导后的首题落在第3页而非第4页。此运行环境须采用上述经核验的兼容流程或更换可兑现侧页约束的引擎，不能直接声称原生打印满足对开。该记录仅描述本次版本，环境升级后须重新实测。
