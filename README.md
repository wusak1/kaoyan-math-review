# 数学试卷批改与复盘

用于 Codex 的考研数学手写试卷批改技能，默认数学二。当前标准为 **v2.8**。

- 按真实原答估分，直接标注错因与订正方案，提供整卷失分分析。
- 左页诊断与闭卷重做，右页主解及分层拓展解法；按实际打印引擎核查左右分页。
- Obsidian 中解析与练习答案默认折叠；概念误区、遗漏知识和构造补入附录。

入口为 [SKILL.md](SKILL.md)，详细规则见 [批改规范 v2.8](references/grading-standard-v2.8.md) 与 [写作及版式](references/writing-and-layout.md)。旧版规范保留用于追溯。

安装到 Codex 的技能目录后，可用 `$kaoyan-math-review` 调用。技能中的本地资料与输出路径是个人环境配置，使用前请按自己的机器调整。仓库仅含技能指令和样式，不附带试卷、教材、答案册、手写作答或生成的复盘文件。
